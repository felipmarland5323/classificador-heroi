# Classificador de Nível de Herói

Projeto desenvolvido como desafio da DIO, utilizando lógica de programação com JavaScript.

## Tecnologias utilizadas

- JavaScript
- Node.js
- Git
- GitHub

## O que o projeto faz

O programa recebe o nome de um herói e sua quantidade de XP, depois classifica o herói em um nível de acordo com sua experiência.

## Níveis

- Ferro
- Bronze
- Prata
- Ouro
- Platina
- Ascendente
- Imortal
- Radiante
